### Hi there 👋
I am Jason Ceballos, an IAM Engineer. Over 20 years of experience designing and securing enterprise identity for large, security-conscious organizations — spanning Okta, Azure AD/Entra ID, Active Directory, and hybrid Workday → Okta → AD ↔ Entra ID architectures. Focused on Zero Trust, SSO/MFA, federation (SAML/OIDC/OAuth2), lifecycle governance, and PKI/ADCS. Also bring core cloud skills across AWS (EC2, S3, VPC, IGW) and Microsoft's Azure/Exchange/AD stack, plus email security experience with DMARC, SPF, and DKIM.
- 🔭 I'm currently working on enterprise IAM modernization — Okta lifecycle automation, Conditional Access/Device Trust, and Azure workload identity initiatives
- 🌱 I'm currently learning toward CISSP certification, working toward a long-term goal of reaching CISO
- 👯 I'm looking to collaborate on IAM/Zero Trust architecture and Okta ↔ Entra ID migration projects
- 💬 Ask me about identity governance, Okta, Zero Trust, or hybrid cloud identity architecture
